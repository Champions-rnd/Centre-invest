# HR-аналитика интервью

Веб-приложение расшифровывает WAV и показывает реплики в виде диалога. По таймкодам можно перейти к записи. После расшифровки рекрутер получает подсказки о темах для следующей встречи, формулировках вопросов и ответах, требующих уточнения.

## Запуск в Windows

Установите Node.js 24 LTS. Откройте терминал в корне проекта и выполните:

```powershell
npm ci
npm run setup:speech
npm run setup:coach
npm run dev
```

Откройте <http://127.0.0.1:5173>. Команда `setup:speech` скачивает в `.speech/` Whisper, FFmpeg и модели. Интернет нужен для установки, а распознавание после неё работает без сети. Загрузка аудио происходит только на сервер приложения.

Команда `setup:coach` устанавливает локальную текстовую модель Qwen и llama.cpp. Загрузка занимает примерно 1,1 ГБ. Сервер запускает модель при первом запросе рекомендаций. Если модель недоступна, приложение показывает подсказки по структуре разговора.

## Архив кандидатов

На главной странице **Кандидаты** доступны поиск, фильтры по специальности и статусу и сортировка по имени, дате последнего интервью или числу записей. Экран **Интервью** показывает отдельные записи с поиском и сортировкой по дате, названию файла или количеству фрагментов.

По кнопке **Добавить кандидата** можно создать карточку с записью или без неё. В меню **Загрузка WAV** доступна пакетная загрузка. Кнопка **Загрузить интервью** в личном деле открывает загрузку для выбранного кандидата.

При создании карточки **Импорт из TXT** заполняет специальность и описание. В файле можно указать `Специальность: …` и `Описание: …` либо написать специальность на первой строке, а описание ниже. ФИО вводится отдельно. Импортированные поля можно исправить перед сохранением. Рядом выбирается WAV, который распознаётся и прикрепляется к карточке при сохранении.

На экране загрузки выберите или перетащите один или несколько WAV. При общей загрузке можно выбрать существующего кандидата или создать нового. Если записи относятся к разным людям, включите выбор кандидата для каждого файла. Сайт обрабатывает файлы по очереди, показывает прогресс и даёт повторить загрузку тех, которые завершились ошибкой.

После расшифровки интервью появятся в личном деле. Из личного дела можно добавить следующие раунды, изменить статус сверки, прослушать исходный WAV и исправить текст и роли участников. Сохранённые правки попадут в следующую выгрузку. **Подготовить сводку** собирает вопросы по расшифровкам всех этапов. Рекомендации с источниками позволяют открыть соответствующее интервью.

В диалоге соседние фрагменты одного участника собраны в одну реплику. Под ней доступны исходные таймкоды. **Уточнить роли** показывает предлагаемые изменения, используя настроенную текстовую модель или правила диалога. Роли определяются по содержанию реплик. Перед сохранением можно прослушать фрагмент, изменить роль или оставить её неопределённой. Подтверждённые роли сохраняются при следующих проверках.

В отчёте **Плюсы и минусы ответов** описываются понятность формулировок, соответствие вопросу, конкретика и результат. Наблюдения связаны с репликами кандидата, а проверка соответствия вопросу также с предшествующей репликой HR. При отсутствии модели доступны наблюдения по структуре расшифровки.

Кнопка **Экспорт Excel** скачивает весь архив. **Excel кандидата** скачивает интервью выбранного человека. Файл `.xlsx` содержит листы «Интервью» и «Расшифровки». Реплики связаны с интервью по ID, время отсчитывается от начала WAV.

SQLite создаётся при первом запуске в `.hr-data/interviews.sqlite`. Аудио и расшифровки сохраняются между перезапусками. Чтобы использовать другой локальный файл, задайте `HR_DB_PATH` в `.env`. При переносе архива сначала остановите сервер и затем скопируйте каталог базы целиком. Каталог `.hr-data/` исключён из Git.

## Запуск на Linux и macOS

Установите [FFmpeg](https://ffmpeg.org/download.html) и [whisper.cpp](https://github.com/ggml-org/whisper.cpp) с поддержкой VAD и вывода JSON. Поместите [`ggml-base.bin`](https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-base.bin) и [`ggml-silero-v6.2.0.bin`](https://huggingface.co/ggml-org/whisper-vad/blob/main/ggml-silero-v6.2.0.bin) в каталог `.speech/`. Если программы или модели в другой папке, укажите пути в локальном `.env` по примеру `.env.example`.

```sh
npm ci
npm run dev
```

Для ИИ-рекомендаций запустите подходящий текстовый сервер, например [llama.cpp](https://github.com/ggml-org/llama.cpp/tree/master/tools/server), и укажите его параметры по инструкции ниже.

## Подключение текстового агента

Укажите в локальном `.env` значения `HR_COACH_BASE_URL`, `HR_COACH_MODEL` и при необходимости `HR_COACH_API_KEY`. Адаптер ожидает OpenAI-совместимый `POST /chat/completions` с поддержкой `response_format: json_schema`. Если провайдер требует префикс `/v1`, включите его в базовый URL. В настроенный текстовый сервис отправляются выдержки из расшифровки и контекст вакансии. Распознавание WAV выполняет Whisper.

## Сборка

```sh
npm run build
npm start
```

Сервер готовой сборки открывается на <http://127.0.0.1:3001>. Остановите `npm run dev`, если он занимает этот порт.

## Обработка записи

- Выберите WAV до 50 МБ и длительностью до 60 минут. FFmpeg приводит поддерживаемые звуковые дорожки к моно PCM 16 кГц для распознавания.
- Whisper определяет язык и возвращает начало и конец фрагментов. Роли HR и кандидата предварительно определяются по тексту. Их можно исправить в редакторе диалога.
- Контекст вакансии необязателен. Добавьте описание роли или до 20 тем, если нужны вопросы по конкретной должности.
- У рекомендаций, относящихся к существующей реплике, есть переход к записи. После правки роли или текста можно обновить рекомендации. Для длинных записей текстовая модель получает выборку реплик.
- Сервер распознаёт одну запись за раз и удаляет временные файлы обработки. При успешном разборе WAV и расшифровка сохраняются в личном деле.
