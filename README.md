# HR-аналитика интервью

Веб-приложение расшифровывает WAV и показывает реплики в виде диалога. По таймкодам можно перейти к записи. После расшифровки рекрутер получает подсказки о темах для следующей встречи, формулировках вопросов и ответах, требующих уточнения.

## Запуск в Windows

Установите Node.js 24 LTS. Откройте терминал в корне проекта и выполните:

```powershell
npm ci
npm run setup:speech
npm run setup:coach
npm run dev
```

Откройте <http://127.0.0.1:5173>. Команда `setup:speech` скачивает в `.speech/` Whisper, FFmpeg и модели. Интернет нужен для установки, а распознавание после неё работает без сети. Загрузка аудио происходит только на сервер приложения.

Команда `setup:coach` устанавливает локальную текстовую модель Qwen и llama.cpp. Загрузка занимает примерно 1,1 ГБ. Сервер запускает модель при первом запросе рекомендаций. Если модель недоступна, приложение показывает подсказки по структуре разговора.

## Запуск на Linux и macOS

Установите [FFmpeg](https://ffmpeg.org/download.html) и [whisper.cpp](https://github.com/ggml-org/whisper.cpp) с поддержкой VAD и вывода JSON. Поместите [`ggml-base.bin`](https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-base.bin) и [`ggml-silero-v6.2.0.bin`](https://huggingface.co/ggml-org/whisper-vad/blob/main/ggml-silero-v6.2.0.bin) в каталог `.speech/`. Если программы или модели в другой папке, укажите пути в локальном `.env` по примеру `.env.example`.

```sh
npm ci
npm run dev
```

Для ИИ-рекомендаций запустите подходящий текстовый сервер, например [llama.cpp](https://github.com/ggml-org/llama.cpp/tree/master/tools/server), и укажите его параметры по инструкции ниже.

## Подключение текстового агента

Укажите в локальном `.env` значения `HR_COACH_BASE_URL`, `HR_COACH_MODEL` и при необходимости `HR_COACH_API_KEY`. Адаптер ожидает OpenAI-совместимый `POST /chat/completions` с поддержкой `response_format: json_schema`. Если провайдер требует префикс `/v1`, включите его в базовый URL. В настроенный текстовый сервис отправляются выдержки из расшифровки и контекст вакансии. Распознавание WAV выполняет Whisper.

## Сборка

```sh
npm run build
npm start
```

Сервер готовой сборки открывается на <http://127.0.0.1:3001>. Остановите `npm run dev`, если он занимает этот порт.

## Обработка записи

- Выберите WAV до 50 МБ и длительностью до 60 минут. FFmpeg приводит поддерживаемые звуковые дорожки к моно PCM 16 кГц для распознавания.
- Whisper определяет язык и возвращает начало и конец фрагментов. Роли HR и кандидата предварительно определяются по тексту. Их можно исправить в редакторе диалога.
- Контекст вакансии необязателен. Добавьте описание роли или до 20 тем, если нужны вопросы по конкретной должности.
- У рекомендаций, относящихся к существующей реплике, есть переход к записи. После правки роли или текста можно обновить рекомендации. Для длинных записей текстовая модель получает выборку реплик.
- Сервер обрабатывает одну запись за раз и удаляет временные аудиофайлы после обработки. Результат хранится в текущей вкладке браузера.
