# HR-аналитика интервью

Приложение помогает рекрутеру вести досье кандидатов, расшифровывать интервью и готовить уточняющие вопросы. WAV обрабатывает ElevenLabs Scribe v2 через ChatCI. Аудиозаписи, расшифровки и правки хранятся в локальном архиве SQLite.

## Быстрый запуск

Понадобятся Git, Node.js 24 LTS с npm и интернет. Для расшифровки нужен действующий ключ ИИ-прокси ChatCI. Если Git и Node.js уже установлены, настройка занимает несколько минут.

### 1. Клонируйте репозиторий и установите зависимости

```sh
git clone --branch main https://github.com/Champions-rnd/Centre-invest.git
cd Centre-invest
node --version
npm ci
```

`node --version` должен вывести `v24.x.x` или новее. `npm ci` установит точные версии из `package-lock.json`.

### 2. Настройте ключ ChatCI

Скопируйте `.env.example` в `.env` в корне проекта. Если `.env` уже есть, откройте его и пропустите копирование.

**Windows PowerShell**

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
```

**macOS и Linux**

```sh
test -f .env || cp .env.example .env
```

Откройте `.env` в редакторе и укажите ключ ИИ-прокси:

```dotenv
HR_CHATCI_API_KEY=ваш_ключ_ИИ_прокси
```

Для просмотра интерфейса ключ можно оставить пустым. Для загрузки и расшифровки WAV нужен действующий ключ. `.env` исключён из Git. [Инструкция организаторов по ChatCI](https://ideamillion.ci-sfedu.ru/#opencode).

### 3. Запустите приложение

```sh
npm run dev
```

Откройте <http://127.0.0.1:5173>. Одна команда запускает интерфейс Vite и API Express на этом адресе. На главной странице появится список кандидатов. Чтобы проверить расшифровку, нажмите **Добавить кандидата**, заполните карточку и прикрепите WAV.

Остановить сервер можно сочетанием `Ctrl+C` в терминале.

## Работа с архивом

- **Кандидаты** показывает карточки, фильтры и поиск. Карточку можно создать с WAV или добавить интервью позже.
- **Импорт из TXT** заполняет специальность и описание в карточке кандидата. Укажите `Специальность: …` и `Описание: …` или напишите специальность первой строкой и описание ниже.
- **Интервью** показывает отдельные записи. Поддерживаются WAV до 50 МБ и длительностью до 60 минут.
- В личном деле можно прослушать WAV по таймкоду, исправить расшифровку и роли, обновить анализ критериев и выгрузить данные в Excel.

Архив создаётся при первом запуске в `.hr-data/interviews.sqlite`. SQLite входит в Node.js. Для переноса архива остановите сервер и скопируйте каталог `.hr-data/` целиком. Чтобы использовать другой файл, задайте `HR_DB_PATH` в локальном `.env`.

## Зависимости и папки

| Файл или папка | Назначение |
| --- | --- |
| `package.json` | Команды npm и список прямых зависимостей |
| `package-lock.json` | Точные версии пакетов для установки через `npm ci` |
| `web/` | Интерфейс на React, TypeScript и CSS |
| `server/` | API Express, архив SQLite, запросы к ChatCI и экспорт Excel |
| `shared/` | Общие типы и схемы проверки данных |
| `.env.example` | Образец локальных настроек |

Vite запускает и собирает интерфейс, `tsx` запускает серверный TypeScript, Multer принимает файлы, Zod проверяет данные, ExcelJS формирует выгрузки. `node_modules/`, `dist/`, `.env` и `.hr-data/` создаются локально и исключены из Git.

## Команды разработки

| Команда | Что делает |
| --- | --- |
| `npm ci` | Устанавливает зависимости по lock-файлу |
| `npm run dev` | Запускает интерфейс и API на 5173 |
| `npm run check` | Проверяет типы TypeScript |
| `npm run build` | Проверяет типы и собирает интерфейс в `dist/` |
| `npm start` | Обслуживает готовую сборку и API. Порт по умолчанию — 3001 |

Vite обновляет интерфейс при правках фронтенда. После изменений сервера или `.env` перезапустите `npm run dev`. Для запуска готовой сборки выполните `npm run build`, затем `npm start`. Оба режима слушают локальный адрес `127.0.0.1`.

## Если запуск не удался

- **`npm` или `node` не найдены.** Установите Node.js 24 LTS и заново откройте терминал.
- **`npm ci` возвращает `EPERM` на Windows.** Остановите запущенный сервер и повторите установку. Если ошибка сохраняется, проверьте запуск в новом клоне.
- **Порт 5173 занят.** Остановите предыдущий процесс в его терминале через `Ctrl+C` и повторите запуск.
- **Сайт просит указать ключ ChatCI.** Проверьте, что в корне проекта есть файл `.env`, а в нём заполнен `HR_CHATCI_API_KEY`. Перезапустите сервер.
- **Нужно проверить API.** Откройте <http://127.0.0.1:5173/api/health>. Рабочий сервер возвращает `{"status":"ok"}`.

## Дополнительные настройки рекомендаций

Быстрый запуск использует ChatCI и встроенные правила анализа. Для своего текстового провайдера можно указать `HR_COACH_BASE_URL`, `HR_COACH_MODEL` и `HR_COACH_API_KEY` в `.env`. Сервер ожидает OpenAI-совместимый `POST /chat/completions` с поддержкой `json_schema`.

На Windows можно отдельно установить локальную текстовую модель командой `npm run setup:coach`. Скачивание модели занимает около 1,1 ГБ. Этот шаг необязателен для запуска сайта и расшифровки.
