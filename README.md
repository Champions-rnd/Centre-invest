# HR-аналитика интервью

Веб-приложение расшифровывает WAV и показывает реплики в виде диалога. По таймкодам можно перейти к записи. После расшифровки рекрутер получает подсказки о темах для следующей встречи, формулировках вопросов и ответах, требующих уточнения.

## Запуск

Установите Node.js 24 LTS. Создайте `.env` по образцу `.env.example` и заполните `HR_CHATCI_API_KEY` персональным ключом ИИ-прокси.

```sh
npm ci
npm run dev
```

Откройте <http://127.0.0.1:5173>. Для расшифровки сервер отправляет WAV по HTTPS в ChatCI, где работает ElevenLabs Scribe v2. Для обработки записи нужен интернет.

## Архив кандидатов

На главной странице **Кандидаты** доступны поиск, фильтры по специальности и статусу и сортировка по имени, дате последнего интервью или числу записей. Экран **Интервью** показывает отдельные записи с поиском и сортировкой по дате, названию файла или количеству фрагментов.

По кнопке **Добавить кандидата** можно создать карточку с записью или без неё. Кнопка **Загрузить интервью** в личном деле открывает загрузку одного или нескольких WAV для выбранного кандидата.

При создании карточки **Импорт из TXT** заполняет специальность и описание. В файле можно указать `Специальность: …` и `Описание: …` либо написать специальность на первой строке, а описание ниже. ФИО вводится отдельно. Импортированные поля можно исправить перед сохранением. Рядом выбирается WAV, который распознаётся и прикрепляется к карточке при сохранении.

На экране загрузки выберите или перетащите один или несколько WAV. Сайт обрабатывает файлы по очереди, показывает прогресс и даёт повторить загрузку тех, которые завершились ошибкой.

После расшифровки интервью появятся в личном деле. Из личного дела можно добавить следующие раунды, изменить статус сверки, прослушать исходный WAV и исправить текст и роли участников. Сохранённые правки попадут в следующую выгрузку.

В диалоге соседние фрагменты одного участника собраны в одну реплику. Под ней доступны исходные таймкоды. **Уточнить роли** показывает предлагаемые изменения, используя настроенную текстовую модель или правила диалога. Роли определяются по содержанию реплик. Перед сохранением можно прослушать фрагмент, изменить роль или оставить её неопределённой. Подтверждённые роли сохраняются при следующих проверках.

В отчёте **Оценка ответов** описываются понятность формулировок, соответствие вопросу, конкретика и результат. Наблюдения связаны с репликами кандидата, а проверка соответствия вопросу также с предшествующей репликой HR. При отсутствии модели доступны наблюдения по структуре расшифровки.

Кнопка **Экспорт Excel** скачивает весь архив. **Excel кандидата** скачивает интервью выбранного человека. Файл `.xlsx` содержит листы «Интервью» и «Расшифровки». Реплики связаны с интервью по ID, время отсчитывается от начала WAV.

SQLite создаётся при первом запуске в `.hr-data/interviews.sqlite`. Аудио и расшифровки сохраняются между перезапусками. Чтобы использовать другой локальный файл, задайте `HR_DB_PATH` в `.env`. При переносе архива сначала остановите сервер и затем скопируйте каталог базы целиком. Каталог `.hr-data/` исключён из Git.

В блоке **Рекомендация ИИ** ChatCI сопоставляет ответы с критериями вакансии. По каждому критерию видны вывод, цитаты кандидата с переходом к аудио, пробелы и вопросы для уточнения. При недоступности ChatCI интерфейс явно показывает предварительную проверку по ключевым словам. Кнопка **Обновить анализ** пересчитывает сохранённый отчёт, а сохранение исправленного диалога пересчитывает его автоматически.

## Подключение текстового агента

Укажите в локальном `.env` значения `HR_COACH_BASE_URL`, `HR_COACH_MODEL` и при необходимости `HR_COACH_API_KEY`. Адаптер ожидает OpenAI-совместимый `POST /chat/completions` с поддержкой `response_format: json_schema`. Если провайдер требует префикс `/v1`, включите его в базовый URL. В настроенный текстовый сервис отправляются выдержки из расшифровки и контекст вакансии.

В Windows командой `npm run setup:coach` можно установить локальную модель для текстовых рекомендаций. Если она недоступна, подсказки формируются по правилам анализа диалога.

## Сборка

```sh
npm run build
npm start
```

Сервер готовой сборки открывается на <http://127.0.0.1:3001>. В режиме разработки интерфейс и API доступны на порту 5173. Vite обновляет интерфейс при изменениях. После правок в коде сервера перезапустите npm run dev.

## Обработка записи

- Выберите WAV размером до 50 МБ и длительностью до 60 минут.
- Scribe определяет язык и возвращает таймкоды и идентификаторы голосов. Роли HR и кандидата предлагаются по тексту с учётом голосов. Их можно исправить в редакторе диалога.
- Контекст вакансии необязателен. Добавьте описание роли или до 20 тем, если нужны вопросы по конкретной должности.
- У рекомендаций, относящихся к существующей реплике, есть переход к записи. После правки роли или текста можно обновить рекомендации. Для длинных записей анализ критериев обрабатывает расшифровку частями.
- При успешном разборе WAV и расшифровка сохраняются в личном деле.
