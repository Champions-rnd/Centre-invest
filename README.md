# HR-аналитика интервью

Веб-приложение расшифровывает WAV и возвращает фрагменты с началом и концом от начала записи. По таймкоду можно перейти к записи. Если указана вакансия, приложение находит в расшифровке реплики по ключевым словам критериев и предлагает вопросы для следующей встречи.

## Запуск в Windows

Установите Node.js 24 LTS. Откройте терминал в корне проекта и выполните:

```powershell
npm ci
npm run setup:speech
npm run dev
```

Откройте <http://127.0.0.1:5173>. Команда `setup:speech` скачивает в `.speech/` Whisper, FFmpeg и модели. Интернет нужен для установки, а распознавание после неё работает без сети. Загрузка аудио происходит только на сервер приложения.

## Запуск на Linux и macOS

Установите [FFmpeg](https://ffmpeg.org/download.html) и [whisper.cpp](https://github.com/ggml-org/whisper.cpp) с поддержкой VAD и вывода JSON. Поместите [`ggml-base.bin`](https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-base.bin) и [`ggml-silero-v6.2.0.bin`](https://huggingface.co/ggml-org/whisper-vad/blob/main/ggml-silero-v6.2.0.bin) в каталог `.speech/`. Если программы или модели в другой папке, укажите пути в локальном `.env` по примеру `.env.example`.

```sh
npm ci
npm run dev
```

## Сборка

```sh
npm run build
npm start
```

Сервер готовой сборки открывается на <http://127.0.0.1:3001>. Остановите `npm run dev`, если он занимает этот порт.

## Обработка записи

- Выберите WAV до 50 МБ и длительностью до 60 минут. FFmpeg приводит поддерживаемые звуковые дорожки к моно PCM 16 кГц для распознавания.
- Whisper автоматически определяет язык и возвращает начало и конец фрагментов. Время и текст стоит сверять с записью. Автоматическое разделение говорящих в текущем движке не включено.
- Чтобы получить только текст и таймкоды, оставьте поля вакансии пустыми. Для отчёта введите описание и до 20 критериев, по одному на строку.
- Отчёт показывает совпадения по ключевым словам, чтобы рекрутер мог проверить контекст. Если исправить текст, нажмите **Пересобрать отчёт**.
- Сервер обрабатывает одну запись за раз и удаляет временные аудиофайлы после обработки. Результат хранится в текущей вкладке браузера.
