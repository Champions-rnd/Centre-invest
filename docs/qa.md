# Сверка с записью

На реальном интервью проверьте минимум три фрагмента. Откройте цитату в отчёте, перейдите к записи и сверяйте текст, начало реплики и спикера на слух. Эталонную расшифровку используйте как дополнительную опору.

| Реплика / ID | Время от начала WAV | Что слышно | Исправление | Что поменялось в отчёте |
| --- | --- | --- | --- | --- |
| | | | | |
| | | | | |
| | | | | |

Для защиты сохраните один реальный пример с ошибкой распознавания. В интерфейсе исправьте текст, нажмите «Пересобрать отчёт» и сравните статус критерия, цитаты или вопрос к кандидату. Если статус не изменился, покажите изменившуюся цитату и объясните, почему она по-прежнему поддерживает вывод.

Проверьте чистый запуск на `dev`: демо, загрузку конкурсного WAV и вакансии, переход по таймкоду, исправление реплики, критерий «Нет данных», повторный анализ и сообщение об ошибке при неверном файле.
