# Контракт API

Источник схем и типов — [shared/contracts.ts](../shared/contracts.ts). Все таймкоды означают миллисекунды от начала исходного WAV. В презентации и интерфейсе можно отформатировать их как минуты и секунды.

| Запрос | Вход | Выход |
| --- | --- | --- |
| `GET /api/health` | — | `{ "status": "ok" }` |
| `GET /api/demo` | — | `InterviewResult` с `mode: "demo"` |
| `POST /api/interviews` | `multipart/form-data` с файлом `audio` и JSON-строкой `vacancy` | `InterviewResult` с `mode: "live"` после подключения обоих адаптеров |
| `POST /api/analyze` | JSON `{ vacancy, transcript }` | `InterviewResult` с анализом исправленной расшифровки |

`vacancy` содержит `description` и массив строк `criteria`. Сервер и клиент получают ID критериев `c1`, `c2` и далее через `vacancyCriteria()`. Передавайте модели ID вместе с названиями. Для повторного анализа порядок критериев сохраняется.

Каждая реплика — `{ id, speaker, startMs, endMs, text }`. Адаптер STT должен вернуть реплики по времени. При объединении слов в реплики учитывайте смену спикера и паузы. Для исправления текста сохраняйте ID, спикера и время.

`InterviewResult` содержит `mode`, `vacancy`, `transcript` и массив `report`. Элемент отчёта хранит поля `criterionId`, `status`, `conclusion`, `evidenceIds`, `gaps` и `nextQuestions`. Модель возвращает один элемент на критерий.

- `supported` — вывод подкреплён репликами, `evidenceIds` содержит их ID.
- `partial` — есть реплики и остаются пробелы, заполняются `evidenceIds` и `gaps`.
- `missing` — подходящих реплик нет, `evidenceIds` пуст, а `gaps` указывает, каких сведений не хватает.

Текст цитаты, спикер и время берутся из `transcript` по ID. Сервер отклоняет неизвестные и повторные ID, отсутствие результата по критерию и неподтверждённые выводы с пустыми ссылками. Схема проверяет структуру. Смысловую связь между выводом и цитатой проверяет участник команды.

Формат ошибок — `{ "error": { "code": "INVALID_WAV", "message": "…" } }`. Ошибки входных данных возвращают 400, превышение размера файла — 413, заглушка адаптера — 501, нарушение контракта провайдером — 502. В адаптерах задайте таймаут и приводите ошибки провайдера к `ApiError` с кратким сообщением.

В начале работы проверьте токен и URL прокси коротким запросом, затем попросите модель вернуть JSON. Содержимое вакансии и расшифровки передавайте как данные. Никаких ключей в браузере, JSON-ответах или Git.
